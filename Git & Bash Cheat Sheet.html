Kompakte Referenz der wichtigsten Befehle für Versionskontrolle und Terminal-Navigation
3
4
KategorieBefehlErklärungBeispiel
5
Gitgit clone <url>Lädt ein bestehendes Remote-Repository von GitHub einmalig als vollständige lokale Kopie (inklusive Historie) auf den eigenen PC herunter.git clone https://github.com/KD260271/hans-spanring-personal-info.git
6
Gitgit statusZeigt den aktuellen Zustand des Arbeitsverzeichnisses und der Staging Area an (welche Dateien neu/untracked, geändert, gestagt oder bereits mit GitHub synchronisiert sind).git status
7
Gitgit add <datei> / git add .Fügt neue oder geänderte Dateien zur Staging Area hinzu und merkt sie damit für den nächsten Commit vor. Mit . werden alle Änderungen im aktuellen Ordner vorgemerkt.git add index.html / git add .
8
Gitgit commit -m "<nachricht>"Speichert alle aktuell in der Staging Area vorgemerkten Änderungen dauerhaft als neuen Versionsstand (Snapshot) im lokalen Repository – versehen mit einer beschreibenden Commit-Nachricht.git commit -m "Add git-cheat-sheet.md with Git and Bash reference"
9
Gitgit logListet die bisherige Commit-Historie des Repositories chronologisch auf (mit Commit-Hash, Autor, Datum und Commit-Nachricht). Mit --oneline wird jeder Commit kompakt in einer Zeile dargestellt.git log / git log --oneline
10
Gitgit pushÜberträgt die lokal erstellten Commits auf das verknüpfte Remote-Repository auf GitHub, sodass der Online-Stand aktualisiert wird.git push
11
Gitgit pullHolt neue Änderungen und Commits vom Remote-Repository auf GitHub ab und führt sie mit dem lokalen Branch zusammen.git pull / git pull --rebase origin main
12
BashpwdGibt den vollständigen Pfad des Ordners aus, in dem man sich gerade befindet (print working directory).pwd
13
Bashcd <pfad>Wechselt in ein anderes Verzeichnis. cd .. springt eine Ordnerebene nach oben, cd ~ führt ins eigene Benutzerverzeichnis (change directory).cd ~/projects/syppre/personal-info/hans-spanring-personal-info / cd ..
14
Bashls / llListet Dateien und Unterordner im aktuellen Verzeichnis auf. ls -la zeigt zusätzlich versteckte Dateien (wie .git) und Details an; ll ist ein praktischer Alias für eine detaillierte Listenansicht (ls -l).ls / ls -la / ll
15
Bashmkdir <ordnername>Erstellt einen neuen Ordner im aktuellen Verzeichnis. Mit -p werden fehlende übergeordnete Ordner gleich mit angelegt (make directory).mkdir images / mkdir -p projects/web/assets
16
Bashtouch <dateiname>Erstellt eine neue, leere Datei (oder aktualisiert den Zeitstempel einer bereits bestehenden Datei).touch git-cheat-sheet.md
17
Bashcat <dateiname>Gibt den gesamten Inhalt einer Textdatei direkt im Terminal aus (concatenate).cat status1.txt
18
Bashcp <quelle> <ziel>Kopiert eine Datei (oder mit -r einen gesamten Ordner) an einen neuen Ort oder unter einem neuen Namen (copy).cp index.html index-backup.html
19
Bashmv <quelle> <ziel>Verschiebt eine Datei bzw. einen Ordner oder benennt sie/ihn um (move).mv foto.jpg images/profil.jpg
20
Bashrm <dateiname>Löscht eine Datei endgültig (ohne Papierkorb). Mit -r lassen sich auch Ordner inklusive Inhalt löschen (remove).rm index-backup.html
21
BashclearRäumt das Terminalfenster optisch auf, indem die bisherigen Ausgaben nach oben gescrollt werden (Alternativ: Strg + L).clear
